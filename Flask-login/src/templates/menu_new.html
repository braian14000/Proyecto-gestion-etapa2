Términos y condiciones de uso

01

Aceptación de los Términos

Al utilizar esta plataforma, el usuario acepta cumplir con las reglas establecidas para la inscripción y participación en los eventos organizados por la UTN.

02

Proceso de Inscripción y Datos del Usuario

  • Para inscribirse en un evento, el usuario debe proporcionar información verídica, incluyendo nombre, apellido, teléfono, correo electrónico (Gmail) y DNI.
  • El sistema validará la disponibilidad de cupos antes de confirmar cualquier inscripción.
  • Restricción de duplicados: El sistema impedirá que un usuario se inscriba más de una vez en el mismo evento. Asimismo, no se permitirá la asistencia de "clones" o registros de identidad duplicados para un mismo evento.
03

Confirmación y Acceso al Evento

  • Es responsabilidad del usuario poseer el comprobante de inscripción con su respectivo código QR, el cual podrá descargar desde la plataforma.
  • Para el ingreso al evento, el organizador verificará la identidad del asistente mediante el DNI o el escaneo del código QR.
04

Cancelaciones y Modificaciones

  • Por el Usuario: El usuario tiene el derecho de cancelar su inscripción previamente realizada a través del sistema.
  • Por la Administración: La UTN se reserva el derecho de suspender o reprogramar eventos. En tales casos, el sistema notificará automáticamente a los usuarios inscritos sobre cualquier modificación o cancelación.
05

Disponibilidad y Funcionamiento Técnico

  • El sistema está diseñado para estar disponible las 24 horas del día y ser compatible con los navegadores Chrome, Edge, Firefox y Safari.
  • La plataforma es responsiva, permitiendo el acceso desde dispositivos móviles, tablets y computadoras.
  • Se busca un tiempo de carga óptimo no mayor a 5 segundos para garantizar una experiencia fluida.
06

Privacidad y Seguridad de Datos

  • Toda la información personal proporcionada por los usuarios será almacenada de forma segura y codificada.
  • Las funciones de administración están protegidas mediante autenticación obligatoria para asegurar que solo personal autorizado gestione los eventos y las listas de inscriptos.
